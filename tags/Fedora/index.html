原因

Atomic /usr 是只读OSTree镜像；系统nodejs的npm默认全局目录指向 /usr/lib/node_modules，root也无法写入，会直接报错 EACCES。

sudo npm‑g 不仅会权限报错，npm脚本以root执行还有安全风险。
